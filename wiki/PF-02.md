# PF-02 Physical Environment Runtime — 물리 환경 런타임

> 구글·엔비디아가 로봇의 두뇌를 발전시켜도, 기기의 내부 상태·안전 조건·실행 검증은 제조사만 안다. 그 지식을 외부 로봇과 AI가 호출하는 런타임으로 만든다.

## 1. Thesis 정의

**한 문장 정의.** 로봇과 AI 에이전트가 집 안의 가전과 공간에서 행동할 때, 별도 학습 없이 "이 기기를 이렇게 쓰면 안전하고, 실행 결과는 이렇게 확인된다"를 제공하는 환경 측 실행 계층.

**Control Point — 물리 환경 행동 모델(Physical Skill Contract).** 로봇이 세탁기 문을 열고, 식기세척기를 돌리고, 냉장고에서 물건을 꺼낼 때 그 행동의 **허용 조건과 완료 검증**을 누가 정의하는가.

| 요건 | PF-02에서의 의미 |
|---|---|
| Access Right | 가전 내부 상태(잠금, 온도, 작동 단계, 오류)에 대한 실시간 접근 |
| Decision Right | 지금 이 행동을 해도 되는지(안전 조건)를 판정 |
| Rejection Right | 안전하지 않은 행동·검증되지 않은 로봇의 호출을 거부 |

**Platform Mechanism.** Runtime(실행 계층) + Standard(행동 계약 규격) + Developer Ecosystem(로봇 OEM·AI 개발자). 수요 측은 로봇 OEM과 AI 개발자, 공급 측은 LG 및 타사 가전·설비.

**플랫폼 전환점.** LG 로봇(CLOiD)이 LG 가전을 쓰는 것은 내부 통합이다. 타사 로봇이 LG 런타임을 호출하고, 타사 가전도 같은 계약 규격을 따르는 순간 플랫폼이 된다.

## 2. 왜 지금인가 — 구조 변화 맥락

- **로봇의 두뇌가 빠르게 범용화되고 있다.** 엔비디아는 CES 2026에서 월드 모델과 휴머노이드용 모델을 오픈소스로 공개했고([[SIG-20261006-15]]), 범용 로봇 모델 스타트업은 기업가치 110억 달러를 인정받았다([[SIG-20261006-16]]). 두뇌가 흔해질수록 차별화는 **환경 쪽**으로 이동한다.
- **가정용 로봇이 가전을 직접 다루기 시작했다.** 1X NEO는 식기세척기 조작과 조리대 닦기를 시연했고([[SIG-20261006-06]]), LG CLOiD는 요리·세탁을 하면서 ThinQ로 가전을 조율한다([[SIG-20261006-17]]).
- **보급 시나리오가 커졌다.** 골드만삭스는 2035년 휴머노이드 650만 대로 전망을 크게 올렸다([[SIG-20261006-18]]). 다만 모건스탠리 장기 전망에서 가정용은 2030년대 후반 이후 본격화된다([[SIG-20261006-19]]).
- **사람 손이 줄어든다.** 외국인 가사관리사 본사업이 무산되면서 가사 노동의 인력 공급 경로가 막혔다([[SIG-20261006-09]]).

## 3. LG의 비대칭 자산

- **기기 내부 상태와 안전 조건.** 펌웨어, 센서, 고장 모드, 작동 단계는 제조사만 안다. 시각 기반 로봇은 문이 잠겼는지, 고온 상태인지, 작동 중인지를 정확히 알 수 없다.
- **가장 넓은 가전 포트폴리오.** 세탁·주방·공조·TV를 모두 만드는 회사는 많지 않다.
- **자체 로봇과 부품.** CLOiD와 AXIUM 액추에이터로 런타임을 내부에서 먼저 검증할 수 있다([[SIG-20261006-17]]). CEO 직속 로봇사업센터가 가정용 로봇을 직접 맡는다([[SIG-20261006-21]]).
- **엔비디아 생태계 파트너.** CES 2026 엔비디아 발표 파트너에 포함됐다([[SIG-20261006-15]]).

## 7. 핵심 불확실성과 반증 조건

- **반증 1** — 범용 로봇이 제조사 API 없이 가전 작업을 일정 수준 이상 안전하게 수행한다는 공개 벤치마크가 나오면 Control Point의 필요성이 약해진다.
- **반증 2** — Matter 등 개방 표준이 "행동 허용 조건·완료 검증"까지 포함하게 되면 제조사 고유 계약의 가치가 줄어든다.
- **불확실성** — 타사 로봇 OEM이 LG 런타임을 쓸 유인(안전 인증, 보험, 책임 분담)을 어떻게 설계할 것인가.

## 8. 관찰 지표

- 로봇 OEM이 가전 API를 공식 지원한다는 발표
- Matter·HCA 규격에 로봇 액션 계층이 추가되는지
- CLOiD 출시 일정과 ThinQ 로봇 API의 외부 개방
- 가정용 로봇의 가전 조작 실패·안전 사고 보고

## 9. Initial Wedge → 2030 End-state

- **Wedge** — LG 가전 + LG 로봇(CLOiD) 조합에서 "안전 행동 계약" 규격을 만들고 내부 검증.
- **Expansion** — 엔비디아 Isaac 등 개발 도구에 LG 가전 행동 모델 공개 → 타사 로봇 OEM 호출 → 타사 가전의 규격 채택.
- **2030 End-state** — 로봇이 집 안에서 가전을 다룰 때 거쳐야 하는 안전·검증 계층의 사실상 표준.
