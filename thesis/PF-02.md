# PF-02 Physical Environment Runtime

로봇 OEM·AI 개발자가 집과 공간에서 행동하기 위해 거쳐야 하는 환경 모델·가전 제어 런타임.

## 관찰 키워드
로봇 파운데이션 모델, 월드 모델, 휴머노이드 SDK, 가정 디지털 트윈, 가전 제어 API, Matter 표준, 로봇 개발자 생태계

## 강화 신호
- 로봇 OEM이 가전·공간 API, 환경 맵을 외부에서 조달
- 가전 제어 표준에 로봇 액션 계층이 추가
- 가정 내 작업 데이터의 가치가 공개적으로 거래·평가됨

## 약화 신호
- 빅테크(Google, NVIDIA, Tesla)가 환경 런타임을 수직 통합해 표준 선점
- 로봇이 가전 연동 없이 시각 기반으로만 작업을 해결
