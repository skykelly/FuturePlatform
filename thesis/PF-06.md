# PF-06 Robot Operations

이종 로봇을 수용해 작업 결과(SLA)를 책임지는 운영 계층. 타사 로봇 수용이 플랫폼 성립 조건.

## 관찰 키워드
RaaS(Robot-as-a-Service), 서비스 로봇 관제, 이종 로봇 통합 플랫폼, 로봇 작업 SLA, 휴머노이드 상용 배치, 서빙·배송·청소 로봇, 지능형 로봇법

## 강화 신호
- 고객이 로봇 구매보다 작업 성과 계약을 선호
- 여러 제조사 로봇을 한 관제로 운영하는 수요·표준 등장
- 인력난 업종에서 로봇 운영 아웃소싱 확산

## 약화 신호
- 로봇 제조사가 운영까지 수직 통합하고 타사 연동 거부
- 서비스 로봇 사고·책임 문제로 도입 지연
